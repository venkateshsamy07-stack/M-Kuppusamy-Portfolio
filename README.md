# M. Kuppusamy - Interactive Portfolio

## Structure
- `index.html` — interactive resume portfolio with About, Education, Skills, Projects, Certificates, Achievements and Contact.
- `lab/index.html` — Web Technology Lab index with nine exercise cards.
- `lab/<exercise>/` — original exercise files from the supplied lab.zip.

## Local preview
For the portfolio and static HTML exercises, open `index.html` in a browser.
For PHP exercises, use a PHP server such as XAMPP or upload to PHP hosting.

## InfinityFree deployment
1. Upload the contents of this folder into `htdocs` (not the outer ZIP folder).
2. The portfolio opens at your domain root; the lab page is at `/lab/`.
3. Each PHP/MySQL exercise has a `db_config.php` file with placeholders. Fill it using the exact MySQL host, username, password and full database name from InfinityFree.
4. Create the tables required by each PHP application before using its database features.
5. Do not commit real database credentials to a public GitHub repository. Keep `db_config.php` private or use a safer server-side configuration method.
